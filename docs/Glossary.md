# Glosarium

| Istilah | Definisi |
|---|---|
| Ticket | Record keluhan dari client sampai closed/cancelled/rejected |
| Client | Organisasi/pelanggan pemilik site |
| Site | Lokasi operasional yang dapat memiliki QR code |
| PIC | Kontak yang bertanggung jawab di sisi client/site |
| Respond Awal | Respons resmi pertama oleh Admin/Head |
| SLA Respond | Durasi ticket dibuat sampai respond awal resmi |
| Assignment | Penugasan satu kelompok teknisi pada ticket/cycle |
| Assignment Member | Satu teknisi dalam assignment |
| Lead Technician | Teknisi koordinator dalam assignment |
| SLA Pengerjaan | Durasi per teknisi dari assigned_at sampai completed_at |
| Check-in | Bukti kedatangan dengan lokasi, foto, dan waktu server |
| Resolution | Pernyataan bahwa pekerjaan telah diselesaikan |
| Closed | Ticket telah diverifikasi dan ditutup |
| Reopened | Ticket aktif kembali setelah resolved/closed |
| Service Cycle | Siklus pengerjaan awal atau setelah reopen |
| Policy Snapshot | Salinan target SLA yang melekat pada instance historis |
| Breach | Target SLA terlewati |
| Live Report | Laporan interaktif di browser sebelum export |
| Audit Log | Catatan actor dan perubahan penting yang append-oriented |
| WITA | Waktu Indonesia Tengah, UTC+8 |
